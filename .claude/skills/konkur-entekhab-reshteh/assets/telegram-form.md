# فرم تلگرام دانش‌آموز

این فرم را مشاور در تلگرام برای دانش‌آموز می‌فرستد و دانش‌آموز جواب‌ها را جلوی سؤال‌ها می‌نویسد. جواب‌ها (همراه با کارنامه) ورودی اسکیل‌اند. **لیست فقط بر اساس همین جواب‌ها ساخته می‌شود:** نه بازهٔ مشاور لازم است، نه تخمین شانس، نه مبلغ شهریه، نه خوابگاه. طول فرم حدود ۲٬۸۰۰ کاراکتر است و در یک پیام تلگرام (سقف ۴٬۰۹۶) جا می‌شود.

## تبدیل جواب‌ها به پروفایل JSON (برای ایجنت)

| سؤال | کلید پروفایل | تبدیل |
|---|---|---|
| ۳ | `gender` | دختر → `"زن"`، پسر → `"مرد"` |
| ۴، ۵ | — | تعیین فایل‌های اکسل: اکسل گروه اصلی، و اگر هنر یا زبان هم دارد، اکسل آن گروه با `--booklet` دوم |
| ۶ | `native_province` | نام استان مثل ستون «استان» اکسل |
| ۷ | `home_city` | |
| ۸ تا ۱۰ | — | در ساخت لیست استفاده نمی‌شود؛ برای پرونده است |
| ۱۱ و ۱۸ | `allowed_courses` | **اشتراک** دوره‌های «مجاز» کارنامه و دوره‌هایی که دانش‌آموز در سؤال ۱۸ نوشته، با مقدارهای دقیق ستون «دوره تحصیلی» (جدول پایین). اگر یکی خالی بود، از دیگری استفاده کن. اگر هر دو خالی بود، `[]` (همهٔ دوره‌ها) و این را در پیام نهایی بگو |
| ۱۸ | `course_order` | همان ترتیب سؤال ۱۸؛ هر گزینه یک عضو، و گزینه‌ای که چند مقدار دارد به‌صورت فهرست، مثل `[["روزانه", "روزانه - غیردولتی"], "شهریه پرداز", ["آزاد تمام وقت", "خودگردان آزاد"]]` |
| ۱۹ | `course_priority` | الف → `"course_first"`، ب → `"within_field"`، ج → `"tiebreak"`؛ بی‌جواب → `"within_field"` |
| ۱۲ | `choices` | به همان ترتیب، هر رشته یک ورودی با عنوان دقیق اکسل (`inspect_booklet.py --search`). نام کلی مثل «پیراپزشکی» یا «مهندسی» را به عنوان‌های مشخص باز کن و اگر ترتیبشان معلوم نیست، از مشاور بپرس |
| ۱۳ | — | این رشته‌ها را وارد `choices` نکن. رشته‌ای را هم که دانش‌آموز ننوشته از خودت اضافه نکن |
| ۱۴ | `priority` | الف → `"field"`، ب → `"place"`، ج → `"balanced"` |
| ۱۵ | `preferred_provinces` | به همان ترتیب |
| ۱۶ | `excluded_provinces` یا `excluded_universities` | استان‌ها در اولی؛ نام شهرها در دومی (در نام دانشگاه یا محل تحصیل جستجو می‌شود) |
| ۱۷ | `preferred_universities` | بخشی از نام دانشگاه، به ترتیب |
| ۲۰ | `accept_commitment` | بله → `true`، خیر → `false`، فقط استان خودم → `["<استان بومی>"]` |
| ۲۱ | `accept_interview` | بله → `true`، خیر → `false` |
| ۲۲ | `retake_next_year` و `will_enroll` | اگر بله: `retake_next_year: true`، و روی ورودی‌هایی که «قطعی» گفته `will_enroll: true`، بقیه `false` |
| ۲۳ | `accept_start_1406` | خیر → `false` |
| ۲۴ | `accept_start_bahman` | خیر → `false` |
| ۲۵ | `is_behyar` | |
| ۲۶ | `special_native_quota` | «نمی‌دانم» → `false`، و در پیام نهایی بگو که مشاور بررسی کند |
| ۲۷ | `notes` | فقط یادداشت؛ انتخاب رشتهٔ آزاد (غیرپزشکی) جداست |
| ۲۸ | `notes` + کلیدهای مرتبط | اگر محدودیتی گفته (مثلاً «فقط تهران»)، با کلیدهای بالا اعمال کن و در پیام نهایی بگو |

**گزینه‌های سؤال ۱۸ ← مقدار ستون «دوره تحصیلی»** (برای `allowed_courses` و `course_order`) (با `inspect_booklet.py` روی اکسل همان سال چک کن):

| گزینه در فرم | مقدار در اکسل (نمونهٔ ۱۴۰۴) |
|---|---|
| روزانه | `روزانه` (و `روزانه - غیردولتی`) |
| نوبت دوم (شبانه) | `نوبت دوم` |
| پردیس خودگردان | `پردیس خودگردان` |
| شهریه‌پرداز دانشگاه‌های علوم پزشکی | `شهریه پرداز` |
| پزشکی، دندانپزشکی و داروسازی دانشگاه آزاد | `آزاد تمام وقت`، `خودگردان آزاد` |
| غیرانتفاعی | `غیرانتفاعی` |
| پیام نور | `پیام نور` |
| مجازی | `مجازی` |
