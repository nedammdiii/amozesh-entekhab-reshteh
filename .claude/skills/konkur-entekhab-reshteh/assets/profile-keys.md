# کلیدهای پروفایل JSON

پروفایل از روی جواب‌های فرم تلگرام ساخته می‌شود (جدول تبدیل در `telegram-form.md`). نمونهٔ کامل: `profile-example.json`. همهٔ کلیدها جز `choices` اختیاری‌اند.

## کلیدهای اصلی

| کلید | معنی | پیش‌فرض |
|---|---|---|
| `student_name` | نام برای عنوان خروجی | — |
| `gender` | `"زن"` یا `"مرد"` | بدون فیلتر |
| `native_province` | استان بومی (برای کدهای «مخصوص بومی») | — |
| `home_city` | شهر محل زندگی (کمی جلوتر در ترتیب) | — |
| `allowed_courses` | دوره‌هایی که هم مجازند و هم داوطلب قبول دارد، با مقدار دقیق ستون «دوره تحصیلی» | `[]` = همهٔ دوره‌ها |
| `choices` | رشته‌ها **به ترتیب علاقه** (پایین را ببین) | **لازم** |
| `priority` | `field` (رشته مهم‌تر)، `place` (شهر و دانشگاه مهم‌تر)، `balanced` | `field` |
| `preferred_provinces` | استان‌های ترجیحی به ترتیب | `[]` |
| `preferred_universities` | بخشی از نام دانشگاه‌های ترجیحی، به ترتیب | `[]` |
| `excluded_provinces` | استان‌هایی که نمی‌رود | `[]` |
| `excluded_universities` | بخشی از نام دانشگاه یا شهری که نمی‌رود | `[]` |
| `accept_commitment` | تعهد خدمت: `true`، `false` یا فهرست استان‌ها | `false` |
| `accept_interview` | کدهای مصاحبه، بورس و گزینش | `false` |
| `accept_start_1406` | کدهای «شروع مهر ۱۴۰۶» (پزشکی و دندانپزشکی) | `true` |
| `accept_start_bahman` | کدهای ورودی بهمن | `true` |
| `is_behyar` | کدهای «ویژه بهیاران» | `false` |
| `special_native_quota` | سهمیهٔ بلایای طبیعی و شهرستان‌های خاص | `false` |
| `retake_next_year` | اگر `true`، کدهای دارای محرومیت فقط در ورودی‌هایی می‌مانند که `will_enroll` دارند | `false` |
| `exclude_codes` | کدهایی که دستی حذف می‌شوند | `[]` |
| `max_codes` | سقف لیست | `150` |
| `university_tiers` | افزودن به سطح‌بندی دانشگاه‌ها، مثل `{"1": ["فردوسی مشهد"], "3": ["..."]}` | — |
| `notes` | یادداشت آزاد (در شیت «ورودی داوطلب» می‌آید) | — |

## هر ورودی `choices`

| کلید | معنی |
|---|---|
| `title` | عنوان دقیق رشته در اکسل (یا `title_contains` برای بخشی از نام) |
| `courses` | فقط این دوره‌ها برای همین رشته (مثلاً پزشکی فقط روزانه) |
| `universities` / `exclude_universities` | محدود کردن یا حذف دانشگاه‌ها برای همین رشته |
| `provinces` | فقط این استان‌ها برای همین رشته |
| `start` | `["مهر"]`، `["بهمن"]` یا `["مهر ۱۴۰۶"]` |
| `max` | حداکثر چند کد از این رشته |
| `will_enroll` | با `retake_next_year`: آیا با قبولی در این رشته حتماً ثبت‌نام می‌کند؟ (پیش‌فرض بله) |

هر کد به **اولین** ورودیِ سازگار تعلق می‌گیرد. یک رشته می‌تواند چند ورودی داشته باشد، مثلاً «پزشکی در فارس» بالاتر از «پزشکی در بقیهٔ کشور».

## ۱۵۰ جا چطور تقسیم می‌شود

اگر کدهای مناسب بیشتر از `max_codes` باشد، جاها بین ورودی‌ها تقسیم می‌شود. وزن‌ها خطی‌اند: با ۷ رشته، اولی ۷ سهم و آخری ۱ سهم. هر رشته حداقل یک جا می‌گیرد و جای خالی رشته‌ای که کد کافی ندارد به بقیه می‌رسد. از هر رشته، کدهایی می‌مانند که از نظر استان، دانشگاه و شهر ترجیح بیشتری دارند. بعد کل لیست به ترتیب علاقه (`priority`) مرتب می‌شود. برای کنترل بیشتر، روی هر ورودی از `max` استفاده کن.
