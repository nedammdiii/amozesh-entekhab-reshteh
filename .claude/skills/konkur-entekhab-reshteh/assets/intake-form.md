# فرم ورودی مشاور → پروفایل JSON

مشاور این اطلاعات را بعد از تماس با دانش‌آموز می‌دهد. هر چه نیامده بود، فقط همان را بپرس (نه کل فرم را). بعد آن را به JSON تبدیل کن (نمونه: `profile-example.json`) و به `scripts/build_list.py` بده.

> **دربارهٔ خوابگاه چیزی نپرس.** عبارت‌هایی مثل «فاقد خوابگاه» در دفترچه یعنی دانشگاه تضمین نمی‌دهد، نه اینکه خوابگاه ندارد.
> **شانس قبولی را هم تخمین نزن.** بازهٔ خوشبینانه/واقع‌بینانه/بدبینانه را مشاور تعیین می‌کند.

## ۱. مشخصات (از کارنامه)

| پرسش | کلید JSON | نمونه |
|---|---|---|
| گروه آزمایشی (برای انتخاب فایل اکسل؛ اگر هنر/زبان هم دارد، فایل آن‌ها هم) | — | تجربی |
| جنسیت | `gender` | `"زن"` یا `"مرد"` |
| استان بومی (طبق کارنامه) | `native_province` | `"فارس"` |
| شهر محل زندگی | `home_city` | `"شیراز"` |
| دوره‌هایی که در کارنامه «مجاز» است **و** خانواده قبول دارد (شهریه) | `allowed_courses` | `["روزانه", "نوبت دوم", "پردیس خودگردان"]` |

مقدار دوره‌ها باید دقیقاً مثل ستون «دوره تحصیلی» اکسل همان سال باشد (با `inspect_booklet.py` ببین).

## ۲. بازهٔ مشاور و ترجیح داوطلب — `choices`

فهرستی **به ترتیب علاقهٔ داوطلب**. هر ورودی یک رشته (و در صورت نیاز محدود به دانشگاه، دوره یا استان) با سطحی است که مشاور گفته:

| کلید | معنی |
|---|---|
| `title` | عنوان دقیق رشته از اکسل (یا `title_contains` برای بخشی از نام) |
| `tier` | `خوشبینانه` (ممکن است بیاورد) / `واقع‌بینانه` / `بدبینانه` (تقریباً قطعی) |
| `courses` | اختیاری: فقط این دوره‌ها (مثلاً `["روزانه"]`) |
| `universities` | اختیاری: فقط دانشگاه‌هایی که نامشان شامل این متن‌هاست |
| `exclude_universities` | اختیاری: حذف این دانشگاه‌ها |
| `provinces` | اختیاری: فقط این استان‌ها |
| `start` | اختیاری: `["مهر"]`، `["بهمن"]` یا `["مهر ۱۴۰۶"]` |
| `max` | اختیاری: حداکثر چند کد از این ورودی (بهترین‌ها بر اساس ترجیح) |
| `will_enroll` | اگر داوطلب قصد کنکور مجدد دارد: آیا با قبولی در این ورودی ثبت‌نام می‌کند؟ (پیش‌فرض بله) |

یک رشته می‌تواند چند ورودی داشته باشد؛ مثلاً «پزشکی روزانهٔ دانشگاه‌های X» خوشبینانه و «پزشکی شهریه‌پرداز» واقع‌بینانه. هر کد به **اولین** ورودیِ سازگار تعلق می‌گیرد، پس ورودی‌های خاص‌تر را بالاتر بنویس.

## ۳. ترجیح مکان و ترتیب

| پرسش | کلید | مقدار |
|---|---|---|
| مهم‌تر کدام است؟ | `priority` | `field` (رشته مهم‌تر)، `place` (شهر/دانشگاه مهم‌تر)، `balanced` |
| استان‌های ترجیحی به ترتیب | `preferred_provinces` | `["فارس", "بوشهر"]` |
| دانشگاه‌های ترجیحی به ترتیب (اختیاری) | `preferred_universities` | `["علوم پزشکی شیراز"]` |
| استان‌های ممنوع | `excluded_provinces` | `[]` |

## ۴. شرایط خاص

| پرسش | کلید | پیش‌فرض |
|---|---|---|
| تعهد خدمت را قبول دارد؟ | `accept_commitment` | `false`؛ یا `true`؛ یا فهرست استان‌ها مثل `["فارس"]` |
| کد مصاحبه‌دار، بورسیه یا گزینش‌دار را قبول دارد؟ | `accept_interview` | `false` |
| بهیار است؟ (کدهای «ویژه بهیاران») | `is_behyar` | `false` |
| مشمول سهمیهٔ بلایای طبیعی یا شهرستان‌های خاص است؟ | `special_native_quota` | `false` |
| اگر رشتهٔ هدف را نیاورد، سال بعد کنکور می‌دهد؟ | `retake_next_year` | `false` |
| کدهایی که مشاور دستی حذف می‌کند | `exclude_codes` | `[]` |

## ۵. اندازهٔ لیست

| کلید | پیش‌فرض | معنی |
|---|---|---|
| `max_codes` | `150` | سقف فرم |
| `tier_caps` | `{"خوشبینانه": 40, "واقع‌بینانه": 80, "بدبینانه": 30}` | حداکثر کد هر سطح؛ جای خالی یک سطح به بقیه می‌رسد |
| `min_pessimistic` | `15` | اگر «بدبینانه» کمتر از این شد، هشدار بده |
